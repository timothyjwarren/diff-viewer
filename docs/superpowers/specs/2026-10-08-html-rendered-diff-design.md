# Rendered HTML diff

## Goal

Review agent-written, self-contained HTML documents (design docs, drafts) as rendered pages instead of raw source. Comments stay anchored to source lines, so thread storage, drift tracking and the agent-facing CLI are unchanged.

## Scope

- Applies to files ending in `.html` / `.htm`.
- Self-contained documents: inline `<style>`, optional inline `<script>`, optional CDN references.
- Out of scope: relative asset resolution, DOM-level diffing, comments on elements generated by scripts at runtime.

## Server

### `src/git/htmlAnnotate.ts`

`annotateHtml(source: string, opts: { scripts: boolean; nonce: string }): string`

- Parses with parse5 using `sourceCodeLocationInfo`.
- Adds `data-dv-line="<n>"` (1-based start line in `source`) to every element.
- Injects, as the first child of `<head>` (creating `<head>` when absent):
  - a CSP `<meta http-equiv="Content-Security-Policy">`:
    - `script-src 'nonce-<nonce>'` when `scripts` is false;
    - `script-src 'unsafe-inline' https:` when `scripts` is true (a nonce would make browsers ignore `'unsafe-inline'`, so no nonce is used in that policy);
    - `default-src 'none'; style-src 'unsafe-inline' https:; img-src data: https:; font-src data: https:` in both cases.
  - the bridge `<script nonce>` (below).
- Tolerates malformed HTML (parse5 error recovery); elements synthesized by the parser have no location and get no attribute.

### `GET /api/rendered`

Query: `repoPath` (must be a repo in the session), `path` (repo-relative), `side` (`old` | `new`), `from` and `to` (the active commit range, both optional), `scripts` (`0` | `1`).
The server resolves the ref the same way the range diff does:
- `new`: `to` = `uncommitted` reads the working tree; any other `to` is a commit; no `to` is `HEAD`.
- `old`: `from` = `uncommitted` is `HEAD`; any other `from` is `<from>^`; no `from` is the repo's `baseRef`.

Reads the file via `readFileAtRef` / `readWorkingTreeFile`, joins lines, generates a random nonce, returns `{ html }`. Absolute paths and paths containing `..` are rejected with 400; a missing file is 404.

## Web

### Source | Rendered toggle

`DiffView` shows a Source | Rendered toggle for `.html` / `.htm` files. Source is the existing view. The choice is per file.

### Rendered mode

- Two panes, old and new, each an `<iframe srcdoc>` holding the annotated HTML from `/api/rendered`. Added files show only the new pane; deleted files only the old pane.
- `sandbox="allow-scripts"` always; never `allow-same-origin`. The iframe is an opaque origin and cannot reach the viewer's origin or API.
- A per-file "Run scripts" toggle, off by default, controls the `scripts` query parameter. Off: the CSP permits only the bridge script (via nonce), so the page's own scripts do not run. On: the CSP additionally permits the page's scripts and https script sources.

### Bridge script

Runs inside each iframe under the nonce. It:

- posts `{ type: "dv-click", line }` to the parent when an element is clicked (innermost element with `data-dv-line`);
- on a `dv-markers` message from the parent, draws numbered markers over elements whose `data-dv-line` matches a thread line, and posts `{ type: "dv-marker-click", threadId }` when one is clicked;
- on a `dv-changed` message, outlines elements whose `data-dv-line` falls in a changed line set (added lines on the new side, deleted lines on the old side, taken from the diff hunks).

The parent checks `event.source` against its own iframes before acting on any message.

### Comments

- `dv-click` opens the existing composer with `side` set to the pane's side and `lineStart`/`lineEnd` set to the element's line.
- Threads whose `file`, `side` and line range match the pane produce markers. Clicking a marker opens the thread in the existing thread UI beneath the iframe.
- Thread creation uses the existing `createThread` API.

### Change marking

Marking is line-based: an element is outlined when its start line is a changed line. An element whose opening tag shares a changed line with unrelated content is over-marked.

## Testing

- `htmlAnnotate`: line numbers for single- and multi-line tags, nested elements, malformed input, missing `<head>`, CSP content for both `scripts` values.
- `/api/rendered`: working-tree and ref reads, `scripts` parameter, 404 for a missing file.
- `DiffView`: toggle visibility only for HTML files, sandbox attribute never contains `allow-same-origin`, scripts toggle changes the request.
- Message handling: `dv-click` produces a composer at the right side and line; messages from unknown sources are ignored.
- Manual: review a real agent-generated document including one that loads a CDN library.
